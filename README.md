# Movie Recommendation Expert System (AI Mini Project)

Rule-based recommendations with a 30-movie local catalogue, IF–THEN rules, forward-chaining preference inference, backward-chaining eligibility checks, rule explanations and preference ranking.

## Setup

1. Install Python 3.10+.
2. Open a terminal inside this folder.
3. Run `python -m pip install -r requirements.txt`.
4. Run `python -m streamlit run app.py`.
5. Open the localhost URL shown by Streamlit.

## Test

`python -m unittest -v test_engine.py`

## CLI demo

`python engine.py`

The program is offline and needs no paid service or API key. Catalogue metadata is illustrative; ratings are not live fetched and do not claim official certification.
